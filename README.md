# SmashKarts Cheat — Downloads

This public repository distributes Windows test builds and usage documentation only. Development source is not published here.

## Download

Get **SmashKartsBot.exe** from [Releases](https://github.com/NH4OH-35/smashkarts-cheat/releases/latest). Windows x64 and internet access are required. Node and the browser are included; no separate installation is needed.

Double-click the executable. It starts **stopped**. Press **Start/F8** to enable the bot; press **Stop/F9** or **Escape** to stop. Close the game window to quit. Use Free For All.

## Manual controls (v0.1.2)

Enter a match, then use the separate buttons in the bot menu:

- **Flight**: W/S or ↑/↓ move forward/backward; A/D or ←/→ move sideways. **R** rises, **F** descends, and Space fires. Stop/F9/Escape turns flight off and restores gravity.
- **Teleport forward**: moves 12 units ahead. A landing surface is required unless flying.
- **Bring weapon crate**: puts an existing ready ordinary crate about 3.5 units ahead. Drive into it to collect the weapon. It returns to its original location after collection, 15 seconds, or pause. This relocates a crate; it does not create new crates.

Manual controls stop autoplay. They start off each launch. Private-room movement and real crate pickup were verified on both observed November 6 game builds; replication to other players remains unverified.

GitHub adds **Source code (zip/tar.gz)** links automatically. Those archives contain this documentation only. Download **SmashKartsBot.exe** to run the mod.

The download uses a fresh local profile and includes no developer login, cookies, saved map memory or K/D history. No ad blocker is preinstalled. This is an unsigned test build.
